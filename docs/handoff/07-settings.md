# Settings

| Key | Name | Type | Default | Scope | Overrides |
|---|---|---|---|---|---|
| appLock | App lock | On / off | On | Whole app | - |
| discreetAlerts | Discreet alerts | On / off | On | Whole app | - |
| hidePrivateDetails | Hide private details when sharing | On / off | On | Whole app | - |
| defaultPrepMinutes | Default prep time | Number | 60 | Whole app | - |
| healthReminders | Health check reminders | On / off | Off | Whole app | - |
| aiAvatarHelp | Allow AI avatar help | On / off | Off | Whole app | - |
| profilesLocalOnly | Keep profiles on this device only | On / off | On | Whole app | - |
| appTheme | App theme | Choice | Midnight Coral | Whole app | - |
| cartoonAvatarStyle | Cartoon avatar style | Choice | Original Cartoon | Whole app | - |
